# QA-004 — 격리 브라우저 E2E 선행 검증

상태: 선행 개발·부분 검증. 전체 MVP 인수 및 최종 승인을 뜻하지 않는다.
제품 기준점: integration `d6f38dabaa738f8c93ce6ba609be8d2e89ae0619`.

## 실행 방법

Java 21, Node 24 이상, Docker Compose가 필요하다. `admin/`에서 lockfile 기반 설치 후 실행한다. macOS 전용 Java 경로는 스크립트에 넣지 않았으며 필요한 경우 현재 터미널의 JAVA_HOME을 설정한다.

```bash
npm ci
npx playwright install chromium
npm run test:e2e
```

Linux CI에서 브라우저 시스템 라이브러리가 없으면 CI 준비 단계에서 `npx playwright install --with-deps chromium`을 실행한다. Playwright는 정확히1.65.0으로 고정했으며 공식 지원 범위에 Node24가 포함된다. 현재 환경은 Node26.8.1·Java21.0.10·PostgreSQL17·Chromium revision1254다.

특정 시나리오만 실행할 때도 기존 서버를 재사용하지 않고 같은 격리 harness를 사용한다.

```bash
npm run test:e2e -- --grep 'account switch'
```

## 격리와 정리

- 매 실행마다 고유 `audit-e2e-<timestamp>-<random>` 프로젝트를 만든다. 명시적 `docker compose -p`가 루트 Compose name을 덮으며 DB_HOST_PORT=0의 실제 localhost 포트를 조회한다. 개발 DB·15432·15434·실행 중인 Admin/API는 재사용하지 않는다.
- 전용 DB의 local Flyway 시드와 회원123 존재를 확인한다. API는 SERVER_PORT=0으로 직접 JAR 실행 후 자기 Tomcat 로그에서 실제 포트를 얻는다. Next는 별도 임의포트·canonical127.0.0.1·전용 API_ORIGIN으로 production build/start한다.
- API·Next readiness와 모든 명령에 시간 상한이 있다. Next가 실제 Ready가 된 뒤에만 브라우저를 실행하며 다른 포트로 조용히 fallback하지 않는다. workers=1·retries=0·테스트마다 새 BrowserContext를 사용한다.
- finally에서 소유 child와 그 Unix process group 또는 Windows 소유 PID tree만 종료하고, 같은 고유 Compose 프로젝트의 컨테이너·볼륨만 삭제한다. 종료 후 해당 label의 컨테이너·볼륨이 없는지 확인한다. 전역 pkill·Docker prune·개발 볼륨 삭제는 사용하지 않는다.
- macOS에서 실제 실행·cleanup을 검증했다. Windows 명령 분기는 포함했으나 이 환경에서 실행하지 않았으므로 Windows 실행 검증은 NOT RUN이다.

## 안전한 증거

trace/video는 기본 off다. 원본 HTTP·쿠키·CSRF·비밀번호·Playwright call log·서버 로그를 공개 reporter에 출력하지 않는다. public 결과는 `admin/test-results/<owned-project>/safe-junit.xml`, `safe-summary.json`, 실패 시 비밀번호 입력을 mask한 `failure-*.png`다. CI 업로드는 이 파일들만 명시적으로 허용한다.

Playwright 원본 결과와 child 로그는 mode0700 임시 디렉터리·mode0600 파일에만 보관하고 기본적으로 종료 시 삭제한다. 실패 진단이 꼭 필요하면 로컬에서만 `QA_E2E_KEEP_PRIVATE=1`을 명시할 수 있으며 해당 private 경로는 CI 업로드에서 제외한다. 원본 storageState/trace를 저장소에 커밋하지 않는다.

정제 reporter 계약 테스트는 sentinel 비밀값을 error/stack/stdout/stderr/attachment에 넣어도 공개 XML/JSON에 남지 않음을 확인한다. 브라우저 시작 같은 전역 실패에 test result가 없어도 실패 JUnit을 생성한다.

```bash
node --experimental-strip-types --test tests/e2e/safe-reporter.contract.ts
```
